### 1. Hook: `useCountdown`

Tüm tiplerde ortak olan geri sayım mantığını yönetmek için bu hook'u kullanacağız.

```javascript
import { useState, useEffect } from 'react';

export const useCountdown = (targetDate) => {
  const [timeLeft, setTimeLeft] = useState(new Date(targetDate) - new Date());

  useEffect(() => {
    const timer = setInterval(() => {
      setTimeLeft(new Date(targetDate) - new Date());
    }, 1000);
    return () => clearInterval(timer);
  }, [targetDate]);

  const formatTime = (ms) => {
    const seconds = Math.floor((ms / 1000) % 60);
    const minutes = Math.floor((ms / 1000 / 60) % 60);
    const hours = Math.floor((ms / (1000 * 60 * 60)) % 24);
    return `${hours.toString().padStart(2, '0')}:${minutes.toString().padStart(2, '0')}:${seconds.toString().padStart(2, '0')}`;
  };

  return formatTime(timeLeft > 0 ? timeLeft : 0);
};

```

### 2. Sticky Bar

`position: fixed` kullanarak ekranın tepesinde sabitleriz.

```jsx
const StickyBanner = ({ title, discount, expiry }) => {
  const [isVisible, setIsVisible] = useState(true);
  const time = useCountdown(expiry);

  if (!isVisible) return null;

  return (
    <div className="fixed top-0 left-0 w-full bg-black text-white py-2 px-4 flex justify-between items-center z-50">
      <div className="flex gap-2 items-center">
        <span>⚡</span>
        <span className="font-bold">{title}</span>
        <span className="text-yellow-400">| {discount}</span>
      </div>
      <div className="flex gap-4 items-center">
        <span className="font-mono font-bold">{time}</span>
        <button onClick={() => setIsVisible(false)} className="hover:text-gray-400">✕</button>
      </div>
    </div>
  );
};

```

### 3. Hero Banner

Grid yapısı ile mobil uyumlu, dikkat çekici bir tasarım.

```jsx
const HeroBanner = ({ title, discount, desc, expiry }) => {
```

### 4. Product Badge

Ürün kartının üzerine "absolute" ile yerleştirilen küçük etiket.

```jsx
const ProductBadge = ({ discount, expiry }) => {
  const time = useCountdown(expiry);
  
  // Sadece 24 saatten az kaldıysa göster
  const show = new Date(expiry) - new Date() < 24 * 60 * 60 * 1000;

  if (!show) return null;

  return (
    <div className="absolute top-2 right-2 bg-red-600 text-white text-xs font-bold px-2 py-1 rounded shadow-lg z-10">
      ⚡ {discount} | {time}
    </div>
  );
};

// Kullanımı:
// <div className="relative">
//   <ProductBadge discount="-%50" expiry="2026-06-07T23:59:59" />
//   <img src={...} />
// </div>

```

### Önemli İpuçları:

* **Performans:** `useCountdown` içindeki interval'i, eğer kampanya bittiyse (time <= 0) `clearInterval` ile durdurmayı unutmayın.
* **State Yönetimi:** Sticky Banner'ın "x" ile kapatılma durumunu `localStorage` veya `sessionStorage` içinde tutarsanız, kullanıcı sayfayı yenilediğinde tekrar açılmasını engelleyebilirsiniz.
* **Esneklik:** `expiry` prop'larını ISO formatında string olarak gönderdiğinizden emin olun.
